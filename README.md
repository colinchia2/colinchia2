## How I build

I use a 20-60-20 rule. The first 20% is mine: I decide what I want, write the plan and explain it. The middle 60% is where Claude Code and my other AI tools build and automate the busywork. The last 20% is mine again: I test, refine and iterate until it's exactly right.

**Built with** Python, React Native (Expo), GitHub, PythonAnywhere · **AI tools** Claude Code, Gemini, Perplexity, Firecrawl, ChatGPT
